# 集中测试目录

所有测试及 Redis 测试服务均在本目录。运行 `go test ./...` 或 `go test ./test/...`；需要无缓存验证时使用 `-count=1`，运行特定集成测试时使用 `-run`。

`unit/` 保存原有私有包测试，按原包路径分组。根目录的 TestInternalPackages 用 Go 官方 overlay 功能把这些文件编译到对应生产包中，保留对私有实现的覆盖，生产目录不会生成测试文件，也不需要为了迁移测试暴露私有符号。文件中的 web2api_unit 标签仅防止它们在 test 子目录按错误的包身份编译，执行器会在临时 overlay 中移除标签。

新增 API / 存储集成测试直接使用生产包的公开入口。`go test -race ./test/...` 会同时对 overlay 中的内部测试启用竞态检测（需要平台支持的 C 工具链）。
